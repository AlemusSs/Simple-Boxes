# Simple_boxes 0.0.1 — Alemus

Простое создание коробок с параметрами для 3D-печати.

## Установка
Blender 4.2 и новее: Preferences → Get Extensions → Install from Disk, выберите Simple_boxes_0.0.1.zip.
Blender 3.6: Preferences → Add-ons → Install, выберите Simple_boxes_0.0.1_legacy.zip и включите Simple_boxes.
В 3D View нажмите N, откройте Simple_boxes → Создать коробку. Выберите основание или крышку и раскройте разделы параметров. Размеры вводятся числами в миллиметрах независимо от единиц сцены; 1 мм соответствует 0,001 Blender unit. Для корректного экспорта используйте метрический масштаб сцены 1. Не масштабируйте объекты в Object Mode для изменения параметрических размеров.

Параметры сохраняются в основании, ссылка из крышки не зависит от имени. Крышка является дочерним объектом основания. Перемещайте пару через основание. Изменения параметров перестраивают сетки автоматически. При ошибке сохраняются предыдущие сетки, сообщение видно в панели. Интерфейс переводится официальным механизмом Blender (включите перевод интерфейса).

## Реализовано
Независимые пары, размеры, дно и глубина, равные секции, перегородки, геометрические скругления, посадочный зазор на сторону, толщина крышки, два положения крышки, автоматические ограничения и обновления, русские и английские подписи, регистрация и отключение.

## Проверки и ограничения
Фактическая среда: Blender 3.6.1 Windows. tests/results.txt содержит результаты запуска tests/smoke.py. Пройдены секции 1×1, 2×1, 2×2, 3×2, 4×4; радиусы 0, 0,5 и завышенный 1000 с ограничением; комбинированные скругления; manifold и площадь граней; длина; ограничение глубины; положения крышки без смены сетки; три пары; сохранение/открытие; повторная регистрация. Около 0,8 секунды на перестроение 4×4 в первом прогоне.

Версия 5.3 указана текущей стабильной на https://www.blender.org/releases/ (проверка 11.11.2026). Запуск на 5.3 и установка через графический интерфейс НЕ проверены. Формат Extension подготовлен по официальному шаблону: https://github.com/blender/blender/blob/main/scripts/templates_toml/blender_manifest.toml . Страницы руководства и API не удалось получить через веб-инструмент.

Это первая реализация с оставшимися отклонениями от полного ТЗ:
- Внутренний вертикальный радиус крышки вычисляется из основания и допуска; отдельного независимого управления им пока нет.
- Внешний радиус ограничен также размерами ячеек, внутренний радиус автоматически увеличивается для сохранения стенок. Это ограничивает независимость радиусов.
- Скругления краёв ограничены третью толщины, внутренний переход крышки — половиной зазора для сохранения посадки. Большие значения фактически обрезаются при построении.
- Бульевы операции могут быть медленными при большом числе секций (до 16×16).
- Автотест не проверяет самопересечения, дубли граней, физическую посадку, все крайние сочетания, русскую панель визуально и STL-экспорт. Проверка manifold сама по себе не доказывает отсутствие самопересечений.
- Модификаторы пользователя сохраняются; проверка касается исходной созданной сетки. Не добавляйте изменяющие форму модификаторы до завершения параметрического редактирования.
- Установка, соответствие актуальному API и пригодность произвольного набора параметров для печати требуют дополнительной проверки. Полное соответствие ТЗ пока не достигнуто.

## Структура
simple_boxes/__init__.py — регистрация; properties.py — параметры; dimensions.py — ограничения и секции; geometry.py — призмы, скругления, Boolean, проверка; builder.py — основание, крышка и обновление; ui.py — панель; localization.py — переводы; blender_manifest.toml — Extension. tests/smoke.py — автоматические проверки, tests/saved.blend — тестовая сцена.

Исправлено при разработке: ограничение внешнего радиуса размерами ячеек и согласование внутренних углов, чтобы угловые полости не выходили за скруглённый внешний контур.

## Исправления по скриншотам
Размеры и переключатель положения крышки перенесены в главную панель. Толщина дна скрыта (старое поле оставлено для совместимости файлов); дно определяется высотой минус глубина, минимум 0,1 мм. Скругления краёв строятся явными дуговыми профилями. После Boolean удаляются избыточные копланарные рёбра. Необходимые топологические перемычки вокруг отверстий могут оставаться в каркасном режиме.
Дополнительные проверки tests/regression.py: семь уровней дугового профиля сверху и снизу, нулевые и ненулевые вертикальные радиусы, замкнутость, все скругления вместе, независимость глубины от старого поля дна, структура главной панели. Проверено в Blender 3.6.1; визуальная проверка в пользовательской сцене не выполнена. Чтобы обновить существующую коробку после переустановки, измените любой размер в Object Mode.
